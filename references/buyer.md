# Покупатель: найти, выбрать, следить

## Найти товар

1. **Рубрика.** `categories --find "телефон"` → `id` рубрики (например `17010`, «Мобильные телефоны»). Искать без рубрики можно, но в выдачу попадут чехлы и запчасти.
2. **Характеристики.** `params --cat 17010 --find "iPhone 13"` → код фильтра и значение (`filter: "phm"`, `value: "5380"`). Без `--find` команда показывает, какие фильтры есть у рубрики. Регион — тоже фильтр: `params --cat 17010 --find "Минск"`.
3. **Поиск по характеристикам.** `search --cat 17010 --param phm=5380 --param ppm=20 --condition used --region 7`.
4. **Поиск по словам.** Тот же запрос с `--query "iphone 13"` вместо `--param`. Он находит объявления, где продавец не заполнил характеристики. Делай оба захода и объединяй по `id`: только по характеристикам теряется часть объявлений (у телефонов модель не заполнена примерно в каждом седьмом).

Остальные опции `search`: `--price-min`, `--price-max` (в рублях), `--seller private|company`, `--delivery` (с Куфар Доставкой), `--sort new|cheap|expensive`, `--limit` (до 200), `--cursor` (следующая страница из `next_cursor`). Несколько регионов: `--region 5 --region 7`.

## Очистить выдачу

У каждого объявления есть `flags`:

| Пометка | Что значит |
|---|---|
| `no_price` | Цена не указана или ноль: часто «обмен», «договорная» |
| `not_sell` | Это не продажа («куплю», «сдам») |
| `suspect_title` | В заголовке «запчасти», «на разбор», «заблокирован», «iCloud» и подобное |
| `duplicate` | Повтор того же объявления от того же продавца |

Пометки ставит код по простым правилам. Дальше прочитай заголовки сам и убери то, что не является искомым товаром: аксессуары, лоты из нескольких вещей, другая модель, «простыня» с перечнем всех моделей подряд. Объявления, найденные только по словам, проверяй внимательнее; при сомнении открой карточку: `item <номер или ссылка>` (там полное описание в `body` и ссылки на фото в `images`).

Пользователю показывай короткий список и одной строкой говори, что и почему убрано («убрал 14: запчасти, обмен, 3 повтора»).

## Выбрать лучшее

1. Посчитай цену группы: [Цена](pricing.md). Без неё «дёшево» и «дорого» не определить.
2. Сначала показывай объявления на 10–40% ниже середины цен без тревожных признаков, дальше по размеру скидки.
3. Цена вдвое ниже середины и меньше — не удача, а повод для проверки: [Безопасность](safety.md). Не поднимай такие объявления в начало списка.
4. По тексту и фото оцени состояние, комплект, противоречия. Для этого открой карточки 3–5 лучших кандидатов, не всех подряд.
5. Плюсы: `delivery` и `safedeal` (оплата и доставка внутри Куфара), несколько своих фото, подробное описание. У компаний есть `seller.unp`.
6. К каждому объявлению в ответе: цена, насколько ниже или выше середины, чем отличается, что уточнить у продавца.

Чего в данных нет: даты публикации (`listed_at` — время последнего поднятия), просмотров, отзывов о продавце, истории цены, постоянного номера продавца. Не выдумывай их.

## Следить за новыми

```bash
kufar.mjs watch add iphone13 --cat 17010 --param phm=5380 --price-max 600 --region 7
kufar.mjs watch check iphone13
```

`watch add` запоминает то, что есть сейчас. `watch check` возвращает только новое (`new`) и объявления, у которых изменилась цена (`price_changed`). Про каждое новое скажи, насколько оно ниже или выше середины цен группы. Проверяй не чаще раза в 5 минут.

Объявления без характеристик слежение по `--param` не увидит. Если это важно, заведи второе слежение с `--query`.

## Список наблюдения

Конкретные объявления, которые пользователь присмотрел:

```bash
kufar.mjs track add https://www.kufar.by/item/1000000001 --note "торг, спросить про батарею"
kufar.mjs track check
```

`track check` показывает, где изменилась цена и какие объявления сняты. В списке до 30 объявлений. Снятое объявление не значит «продано»: продавец мог просто его убрать.

## Где хранится состояние

Слежение и список наблюдения лежат в `~/.local/state/kufar-skill` (или в каталоге из `KUFAR_STATE_DIR`). Хранятся только номера виденных объявлений с последней ценой и заметки пользователя. Выдачу целиком не сохраняй ни в файлы, ни в таблицы: правила Куфара запрещают складывать его материалы в базы данных.
