# Куфарыч

Скилл для ИИ-агента, который работает с Куфаром (kufar.by) за вас. Ищет вещи, считает честную цену по похожим объявлениям, проверяет продавца и переписку на обман, следит за новыми объявлениями, подаёт и правит ваши объявления, отвечает в чате.

Подходит любому агенту, который умеет запускать команды в терминале: Claude Code, Codex и другим. Нужен только Node.js 22 или новее. Зависимостей нет, отдельный сервер не нужен.

Проект неофициальный, с Куфаром не связан.

[In English](#in-english)

## Что умеет

Без входа в аккаунт:

- поиск по словам, рубрике, региону и характеристикам, с пометками у объявлений без цены, «куплю» и «на запчасти»;
- оценка цены: сколько просят за такую же вещь, дорого это или дёшево, за сколько выставить свою;
- сравнение нескольких объявлений: чем они различаются и какое выгоднее;
- проверка объявления или присланного сообщения на признаки обмана;
- слежение за новыми объявлениями по запросу и за ценой выбранных.

После входа в ваш аккаунт:

- ваши объявления со статистикой просмотров, причина отказа модератора;
- разбор входящих, ответ покупателю, первое сообщение продавцу, торг;
- подготовка объявления: рубрика, поля формы, название и описание, которые находит поиск Куфара, подготовка фото;
- фото уходят на Куфар без координат съёмки и других скрытых данных; HEIC с айфона на macOS переводится в JPEG;
- несколько вещей за один раз: список, цены, общий показ и подача по одной;
- подача, правка, снятие, возврат, продление и удаление объявления.

Всё, что меняет аккаунт или уходит другим людям, агент сначала показывает вам и делает только после вашего «да».

## Как пользоваться

Говорите с агентом обычными словами:

- «найди на Куфаре зарядную станцию 7 кВт до 500 рублей в Минске»
- «дёшево ли это?» и ссылка на объявление
- «сравни эти три объявления» и ссылки
- «не развод ли это?» и текст сообщения от покупателя
- «следи за новыми объявлениями по велосипеду Stels»
- «что мне написали на Куфаре?»
- «выставь на Куфаре катушку зажигания за 59 рублей, фото в папке»
- «сними объявление, продал»

## Установка

1. Поставьте [Node.js](https://nodejs.org) 22 или новее.
2. Скачайте репозиторий:

   ```bash
   git clone https://github.com/AndyShaman/kufar-skill.git
   ```

3. Положите скилл туда, где ваш агент ищет скиллы. Для Claude Code:

   ```bash
   mkdir -p ~/.claude/skills/kufar
   cp -R kufar-skill/SKILL.md kufar-skill/scripts kufar-skill/references kufar-skill/assets ~/.claude/skills/kufar/
   ```

   Другому агенту достаточно указать на файл `SKILL.md`: в нём написано, какие команды запускать.

4. Откройте новую сессию агента и попросите что-нибудь найти на Куфаре.

Тесты остаются в репозитории и для работы скилла не нужны. Запуск: `node --test tests/`.

## Вход в аккаунт: что важно знать

Поиск, цены и проверка на обман работают без входа. Вход нужен только для ваших объявлений и переписки.

1. Куфар не выдаёт отдельных ключей для программ. Скилл работает с тем же ключом входа, что и сайт. Такой ключ даёт полный доступ к аккаунту примерно на год.
2. Вход вы делаете сами: в окне браузера, которое открывает скилл, или по коду, который Куфар присылает в Viber или SMS. Пароль агент не видит и не спрашивает.
3. Ключ лежит в файле на вашем компьютере, доступ к файлу только у вас. Никуда, кроме Куфара, он не отправляется.
4. Агент работает от вашего имени и технически может прочитать любой ваш файл, в том числе этот. Скилл запрещает агенту показывать и передавать ключ, но полной стены изнутри скилла нет. Как закрыть агенту доступ к файлу, написано в `references/key-protection.md`.
5. Ключ, которым не пользовались 30 дней, скилл удаляет с компьютера при следующем запуске. Если скилл больше не запускать совсем, файл с ключом так и останется лежать, а на Куфаре ключ действует до конца срока: гасит его только выход. Перестали пользоваться - попросите агента выйти из аккаунта.
6. Куфар может поменять сайт, и часть команд перестанет работать до обновления скилла. Разрешения на такие программы Куфар не давал и может ограничить аккаунт, если сочтёт действия автоматическими. Пользуйтесь на свой риск.

## Чего скилл не делает

- Не платит и не подключает платное: поднятия, пакеты, рассрочку, доставку Куфара.
- Не просит и не принимает данные карты и коды из SMS, кроме кода входа на Куфар, который вы сами запросили.
- Ничего не ставит в систему, фоновых заданий нет. Слежение проверяется, когда вы об этом просите.
- Не выдаёт цены объявлений за цены сделок: за сколько вещь продана, Куфар не показывает.
- Не выгружает Куфар целиком: ищет небольшими порциями и с паузами.

## In English

Kufarych is an agent skill for Kufar.by, the Belarusian classifieds site: clean search, price check against similar listings, scam check, watching for new listings, and, after you log in, your own listings and chat (post, edit, take down, reply). It works with any agent that can run shell commands, needs Node.js 22+ and has no dependencies. Unofficial, not affiliated with Kufar. The skill's instructions are written in Russian.
